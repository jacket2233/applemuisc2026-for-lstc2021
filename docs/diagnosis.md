# 本次排查结论与证据边界

环境：Windows 10 Enterprise LTSC 2021 / Build 19044，Apple Music 包 `1.1540.23041.0`。

## 过程与有效做法

- 直接运行解压 EXE 缺少包身份；应注册清单并通过包 AUMID 激活。
- 清单原要求 Windows.Desktop `10.0.19045.0`；仅降至 `10.0.19044.0`，保留 VCLibs 版本、原 Publisher 和原应用扩展。
- 临时 `.LTSC` 身份虽能启动 UI，却观察到 AMPLibraryAgent 异常、资料库 COM 失败和页面转圈。二进制检查提示内部存在原始包名比较及未知包分支。
- 恢复 `AppleInc.AppleMusicWin` 原始身份后，AppleMusic 与 AMPLibraryAgent 均保持运行；原始身份激活和资料库 COM 探测返回成功。
- 历史 EXE/DLL 对比记录为 148 个已检查、0 个不一致、0 个缺失。该 JSON 只是摘要，不是数字签名、不证明任何未来下载的真实性。
- 用户已反馈登录和授权成功。本项目不提取、复制或重置账户数据。

## 不应过度推断

这些证据支持“.LTSC 包名引起后台兼容问题”，但不能证明它是所有联网、认证或页面问题的唯一原因。主页、广播、详情页的最终 UI 加载结果仍待用户确认，播放/DRM/下载也未全部验证。

## 没有纳入的试验

Publisher/包身份探针、证书试验、数据库读写、进程注入、二进制 patch、账户重置及原始 ETL 均不作为安装流程。普通 WebView 缓存曾单独隔离过，但并非最终已证明的根因修复，不提供自动清缓存按钮。
