# 安全与隐私边界

- 不重新分发 Apple EXE/DLL，不收集账户、密码、令牌、订阅或 DRM 数据。
- 不修改来源包；准备目录必须全新，不提供强制覆盖/递归清理功能。
- 不用硬链接，不接收来源目录中的联接点或符号链接。
- 清单身份、Publisher、x64 架构与版本严格匹配；只允许 19045 → 19044 的目标系统调整。
- 复制后 EXE/DLL 哈希必须一致，注册前再次校验。这证明复制前后相同，不代替安装来源的可信性验证。
- 修改后的包不再拥有原始清单签名保障；仅隔离新副本的失效签名元数据，不安装自签证书。
- 不改 DLL、TLS 校验、证书、hosts、代理、StateRepository、系统策略或 Windows 版本。
- 不自动结束进程；注册/回滚前由用户退出应用。
- 日志仅导出 OS、包状态、进程以及崩溃模块/异常码等限定字段；本地用户路径做替换，不导出原始事件文本或完整 ETL。
- 准备/注册记录含本机文件路径，只应保留本地。分享任何日志前自行审查。
- 当前不附 Apple 完整清单；自编最小夹具仅供模拟测试，禁止拿它注册应用。未来兼容性未知。
## 法律与签名不是同一层面的保证

以上技术边界不构成授权或合法性判断。脚本虽不改 EXE/DLL，仍复制程序并修改包清单；开发模式注册与隔离失效签名元数据不是 Apple 签名认证。详见 `../DISCLAIMER.md` 与 `legal-review.md`。

诊断仅替换部分本机路径，不是完全匿名化；部署记录可能含路径、用户名/SID 等。不要直接把本地记录上传 Issues。项目不主动向维护者上传数据，不代表 Apple 应用本身不联网或不处理数据。
